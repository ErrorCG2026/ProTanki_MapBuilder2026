# ProTanki MapBuilder 2026

Редактор карт для ProTanki на Unreal Engine 5. Загружает библиотеки пропов (`.tara` / папки с `library.xml`), открывает и сохраняет карты в формате XML игры, умеет оптимизировать коллизию.

## Скачать

Готовая сборка — в разделе **[Releases](../../releases)**. Скачайте архив `MapBuilder-<версия>-Win64.zip`, распакуйте в любую папку и запустите `MapBuilder-<версия>.exe`.

**Требования:** Windows 10/11 x64, видеокарта с поддержкой DirectX 12.

## Быстрый старт

1. **Библиотеки:** меню загрузки → *Load libs* и выберите папку с библиотеками. Или просто перетащите папку из проводника в окно редактора.
2. **Карта:** *Load map* / *Clear and load map* и выберите `.xml`. Или перетащите `.xml` в окно.
3. **Сохранение:** *Export* — карта сохраняется в `.xml`.

## Управление

Схема переключается в **Settings** (шестерёнка справа сверху) → *Controls*. Выбор запоминается.

### New (по умолчанию)

| Действие | Клавиши |
|---|---|
| Полёт камеры | ПКМ + WASD |
| Выделение | ЛКМ, Ctrl+ЛКМ — добавить к выделению, Ctrl+A — всё |
| Гизмо | Q — перемещение, E — поворот |
| Двигать выделенное | стрелки, W/S — вверх/вниз (по сетке), Alt + стрелки — копия |
| Привязка к сетке XY / Z | R / T |
| Фокус на выделенном | F |
| Снять выделение | Esc |
| Удалить | Delete |
| Отмена | Ctrl+Z |

### Legacy (как в старом Flash-редакторе)

| Действие | Клавиши |
|---|---|
| Снять выделение | Esc |
| Удалить выделенное | Delete, C |
| Поворот выделенного на 5° | Z — против часовой, X — по часовой (Shift — 15°) |
| Размер сетки | K (500 → 250 → 125 …) |
| Зум | Ctrl + = / Ctrl + − |
| Сброс направления камеры | Ctrl + 0 |
| Двигать проп или курсор | перетаскивание ЛКМ, стрелки |
| Копировать и двигать | Shift + перетаскивание |
| Двигать по вертикали | V + перетаскивание, W / S |
| Поставить проп | клик по пропу в библиотеке → Space (ставится в точку курсора) |
| Отразить текстуру | F |
| Выделить пересекающиеся пропы | Ctrl + Q |
| Панорама | колесо мыши (зажать) + движение |
| Вращение вокруг точки | Alt + колесо (зажать) |
| Поворот камеры | N / M, Tab — на месте / вокруг объекта |
| Движение камеры | NumPad 8/2/4/6, NumPad 9/3 или PgUp/PgDn — вверх/вниз |
| Ускорение | Shift |
| Привязать спавн к точке DOM | Ctrl+клик по спавну → Ctrl+клик по точке |
| Загрузить библиотеки / карту | перетащить папку / `.xml` в окно |
